    PSOC™ 4 safety test library training¶

    This training introduces the safety test library for PSOC™ 4 devices.

    Device family¶

    • PSOC™ 4

    Training level¶

    • E3: Advanced

    Prerequisites¶

    Recommended training¶

    • This training does not cover basic concepts of ModusToolbox™ and PSOC™ 4.
    • For an introduction into the PSOC™ 4 digital peripherals, see PSOC™ digital peripherals training
    • For an introduction into CAPSENSE™ on PSOC™ 4 MCUs, see PSOC™ 4 CAPSENSE™ using PSOC™ 4000T and PSOC™ 4100T Plus training

    Tools (see training manual for versions and installation instructions)¶

    • ModusToolbox™ with Eclipse IDE
    • ModusToolbox™ Programming tools

    Hardware¶

    • MiniProg4 (CY8CKIT-005-A)
    • CY8CPROTO-041TP
    • Jumper wires (4 nos)
    • 150 kΩ and 75 kΩ through-hole resistors

    Duration¶

    • ~90 min video with hands-on labs

    Agenda¶

    1. Introduction to functional safety standards
    2. Introduction to the Safety Test Library (STL)
    3. Description of the core peripheral tests
    4. Lab 1: Executing the core peripheral tests
    5. Description of the analog peripheral tests
    6. Lab 2: Executing the analog peripheral tests
    7. Description of the UART loopback test
    8. Lab 3: Executing the UART loopback test

    Expected outcome¶

    • Become familiar with functional safety standards
    • Become familiar with the Safety Test Library (STL) available with ModusToolbox™
    • Be able to execute safety tests on PSOC™ devices

    Content¶

    • Presentation
    • Training manual
    • Lab Solutions

    How to use this training?¶

    1. Download the training content.
    2. Watch the video or review the presentation at your own pace.
    3. Follow the step-by-step instructions in the training manual during the hands-on sections.
    4. Use the provided source files if needed to verify the solution.
