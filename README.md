# PSOC™ 4 safety test library training
This training introduces the safety test library for PSOC™ 4 devices. 


## Device family
- [PSOC™ 4](https://www.infineon.com/products/microcontroller/32-bit-psoc-arm-cortex/psoc-4-mcu)


## Training level
- E3: Advanced

## Prerequisites 

### Recommended training
- This training does not cover basic concepts of ModusToolbox™ and PSOC™ 4.
  - For an introduction into the PSOC™ 4 digital peripherals, see [PSOC™ digital peripherals training](https://github.com/Infineon/mtb-training-psoc-digital-peripherals)
  - For an introduction into CAPSENSE™ on PSOC™ 4 MCUs, see [PSOC™ 4 CAPSENSE™ using PSOC™ 4000T and PSOC™ 4100T Plus training](https://github.com/Infineon/mtb-training-psoc-4-msclp-capsense)

### Tools (see [training manual](#content) for versions and installation instructions)
- [ModusToolbox™ with Eclipse IDE](https://softwaretools.infineon.com/tools/com.ifx.tb.tool.modustoolboxsetup)
- [ModusToolbox™ Programming tools](https://softwaretools.infineon.com/tools/com.ifx.tb.tool.modustoolboxsetup)

## Hardware
- [MiniProg4 (CY8CKIT-005-A)](https://www.infineon.com/evaluation-board/CY8CKIT-005-A)
- [CY8CPROTO-041TP](https://www.infineon.com/evaluation-board/CY8CPROTO-041TP)
- Jumper wires (4 nos)
- 150 kΩ and 75 kΩ through-hole resistors

## Duration
- ~90 min video with hands-on labs

## Agenda
1. Introduction to functional safety standards
2. Introduction to the Safety Test Library (STL)
3. Description of the core peripheral tests
4. Lab 1: Executing the core peripheral tests
5. Description of the analog peripheral tests
6. Lab 2: Executing the analog peripheral tests
7. Description of the UART loopback test
8. Lab 3: Executing the UART loopback test

## Expected outcome
- Become familiar with functional safety standards
- Become familiar with the Safety Test Library (STL) available with ModusToolbox™
- Be able to execute safety tests on PSOC™ devices
